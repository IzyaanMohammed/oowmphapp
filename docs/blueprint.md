# **App Name**: MPH Booking Central

## Core Features:

- User Authentication: Secure user login with Firebase Authentication, differentiating verified teachers from unverified users and admins.
- Role-Based Calendar Dashboard: A dynamic calendar view displaying session bookings, tailored to the user's role (teacher, unverified, admin).
- Session Management: Allows verified teachers to add, edit, and delete session bookings with real-time updates.
- Automated Notifications: Firebase Cloud Functions send daily booking summaries, upcoming session reminders, and system updates to users.
- Search and Filter: Enable users to search and filter sessions by teacher, program name, date, and other criteria to quickly find specific sessions.
- Human Like: Make the design more human like

## Style Guidelines:

- Primary color: Royal blue (#4169E1), symbolizing trust, authority, and stability, essential for a school management tool.
- Background color: Light blue (#E6EFFF), creating a calm and clean interface.
- Accent color: Lavender (#E6E6FA), providing a gentle contrast to draw attention to key actions and notifications.
- Body and headline font: 'PT Sans' for readability and a modern feel.
- Code font: 'Source Code Pro' for any displayed code snippets.
- Use clean, minimalist icons representing various school activities and functions for easy navigation.
- Maintain a clear, structured layout with a calendar-focused dashboard, ensuring easy access to session details and management features.
- Implement subtle transitions and loading animations to provide a smooth user experience when navigating and updating bookings.
